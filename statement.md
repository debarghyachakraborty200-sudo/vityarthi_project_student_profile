# Problem Statement

## Problem statement

In many colleges, marks and attendance are still calculated by hand or in separate sheets. This takes time and mistakes can happen while adding marks, finding the percentage or checking whether a student has the minimum 75% attendance. This project is a simple Python program that stores the marks and attendance of students and calculates the result automatically.

## Scope of the project

- Works for many students in one run of the program
- 5 subjects with marks from 0 to 100
- Calculates total, percentage, grade and pass/fail result (40% is the pass mark)
- Calculates attendance percentage and eligibility (75% is required)
- Shows a report for one student and a summary of the class
- Runs in the console. No database, GUI or internet is used, so data is not saved after the program closes

## Target users

- Teachers or class coordinators who want to check results and attendance quickly
- Students who want to check their own percentage, grade and attendance
- Beginners who want to see a simple example of a menu-driven Python program

## High-level features

1. Student management (add student)
2. Marks and grade calculation
3. Attendance calculation and eligibility check
4. Student report and list of all students
5. Class summary with topper and rank list
6. Input validation
